# Quick Obsidian Clipper — Screenshots-Konzept (5 Motive)

Chrome Web Store erfordert mindestens 1 Screenshot, empfohlen werden 3–5.
Format: 1280×800 oder 640×400 px, PNG oder JPEG.

---

## Motiv 1 — Clip-Aktion auf einem Artikel

**Dateiname:** `screenshot-01-clip-action.png`

**Was zu sehen ist:**
- Browser mit einem Artikel (z. B. Medium oder Blog) im Hintergrund
- Extension-Popup offen: "Clipped!" Bestätigung mit grünem Häkchen
- Dateiname des generierten Markdown-Files sichtbar (`2026-06-11--artikel-titel.md`)
- Timestamp und Datei-Download-Symbol

**Botschaft:** Es funktioniert. Eine Aktion, ein File.

---

## Motiv 2 — Erzeugtes Markdown in einem Editor

**Dateiname:** `screenshot-02-markdown-output.png`

**Was zu sehen ist:**
- Markdown-Datei geöffnet in Obsidian (oder einem Code-Editor)
- YAML-Frontmatter oben: `title`, `url`, `date`, `tags`, `word_count`, `reading_time`
- Sauber formatierter Inhalt darunter: Überschriften, Absätze, Links erhalten
- Keine Ads, keine Navigationsleiste, kein Tracking-Fragment

**Botschaft:** Die Ausgabequalität — das ist der Kernwert.

---

## Motiv 3 — Bulk-Clip mehrerer Tabs

**Dateiname:** `screenshot-03-bulk-clip.png`

**Was zu sehen ist:**
- Browser mit 8 offenen Tabs (verschiedene Seiten)
- Bulk-Clip-Statusseite (`bulk-clip-status.html`) offen
- Fortschrittsbalken: "Clipping 5 / 8"
- Liste der Tabs mit Status-Icons: ✓ geclippt / ⌛ in Bearbeitung / ✗ Fehler

**Botschaft:** Ganze Research-Sessions auf einmal archivieren.

---

## Motiv 4 — Duplikats-Warnung

**Dateiname:** `screenshot-04-duplicate-detection.png`

**Was zu sehen ist:**
- Extension-Icon mit grünem Badge (Häkchen) auf einem Tab
- Popup zeigt: "Already clipped 3 days ago"
- Schaltflächen: "Clip again" / "View existing clip"
- URL ohne Tracking-Parameter angezeigt

**Botschaft:** Keine versehentlichen Duplikate — intelligente Erkennung.

---

## Motiv 5 — Optionsseite

**Dateiname:** `screenshot-05-options.png`

**Was zu sehen ist:**
- Options-Seite geöffnet
- Download-Pfad-Feld: `~/Downloads/Obsidian-Clips/`
- Site-Handler-Einstellungen (YouTube-Handler ✓ aktiv, Twitter ✓ aktiv, Archive.ph ☐ deaktiviert)
- Duplicate-Detection-Fenster: 30 Tage
- Keyboard-Shortcuts-Übersicht

**Botschaft:** Einfach konfigurierbar, sinnvolle Defaults.

---

## Hinweise zur Screenshot-Produktion

- Echte Seiten verwenden, keine Placeholders (z. B. Artikel von einem öffentlichen Blog).
- Persönliche Daten in Dateipfaden unkenntlich machen (Username ersetzen).
- Obsidian-Screenshot: Vault-Name neutralisieren.
- Chrome-Fenster auf 1440×900 setzen, dann auf 1280×800 zuschneiden.
