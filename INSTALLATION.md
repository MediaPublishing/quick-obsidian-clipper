# Install Quick Obsidian Clipper

Quick Obsidian Clipper is currently installed as an unpacked browser extension.

## 1. Get the code

### Option A: Clone with Git

```bash
git clone https://github.com/MediaPublishing/quick-obsidian-clipper.git
cd quick-obsidian-clipper
```

### Option B: Download ZIP

1. Open the GitHub repo
2. Click **Code**
3. Click **Download ZIP**
4. Unzip the file

## 2. Open the extensions page

- Chrome: `chrome://extensions`
- Brave: `brave://extensions`
- Arc: `arc://extensions`
- Edge: `edge://extensions`

## 3. Enable Developer mode

Turn on **Developer mode** in the top-right corner.

## 4. Load the extension

1. Click **Load unpacked**
2. Select the root folder of this repository
3. The Quick Obsidian Clipper icon should appear in your browser

## 5. Configure it

1. Open the extension's **Options** page
2. Set your preferred download folder
3. Test it on any page

## Recommended Obsidian setup

Point the download folder directly at a folder inside your vault, for example:

```text
/Users/you/Documents/Obsidian/Vault/Clippings
```

That way every clip lands in Obsidian-ready markdown immediately.

## Updating to a newer version

If you cloned the repo:

```bash
git pull
```

Then go back to the extensions page and click the reload button on the extension card.

If you installed from ZIP, download the latest ZIP, replace the local folder, and reload the extension.
